\## ✨ Overview



\*\*CareerPilot AI\*\* is a full-stack placement-preparation platform designed to bring the major stages of placement preparation into one connected workspace.



Instead of managing resumes, DSA practice, interview preparation, skill development and career planning across different tools, CareerPilot AI provides a unified preparation workflow.



\### The platform brings together:



\- 📄 AI Resume Analysis

\- 🤖 ATS-oriented Resume Feedback

\- 💻 DSA Progress Tracking

\- 🎤 AI Interview Preparation

\- 🎯 Skill Gap Analysis

\- 🗺️ Career Roadmaps

\- 📊 Preparation Analytics

\- 💼 Professional Profile Analysis



The application is built using \*\*React + Vite\*\* on the frontend, \*\*FastAPI\*\* on the backend, \*\*Firebase Authentication + Firestore\*\* for identity and persistence, and \*\*Google Gemini\*\* for AI-powered analysis.



> 🚧 CareerPilot AI is an actively developed project.
